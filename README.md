# wifi-word-01 — One Word for Your Wi-Fi

## The bounty

[One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) — send a single word describing your Wi-Fi. The funniest, truest word wins the $2 reward. Free to enter. Closes Sat 28 Nov 2026 18:35 WIB.

## The entry

**Schrödinger** — 11 characters, one word.

The quantum-physics joke for a connection that is both working and broken at the same time: full bars, page won't load, and you only find out which state it's in when you try to use it. Grok (grok-4.3) scored this candidate 9/10 — a witty quantum reference capturing the "both working and broken" Wi-Fi paradox with fresh specificity.

## How to run

```sh
OUTPUT_DIR=/tmp/out node main.ts
```

This writes the word exactly as-is (no trailing newline) to `$OUTPUT_DIR/entry.txt`, reads it back, and verifies it byte-for-byte.
